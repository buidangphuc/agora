`Dialog` can run controlled without a trigger (`triggerLabel` optional; focus returns to the opener), takes an optional `description`, a `footer` slot for actions, a `size` (`sm`/`md`/`lg`/`xl`) and a `closeLabel` for the header close button. It renders a native `dialog` element with `aria-modal`. Tokens add the dialog header, body, footer, close button and size maps.
