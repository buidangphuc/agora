`@fe-platform/ui` adds the data display components `Skeleton`, `PageSkeleton`, `Progress`, `Descriptions` and `Statistic`. `Descriptions` and `Statistic` take a `fallback` node for error states, and `Statistic` takes `tone="danger"`. Tokens add the class maps for these components, and the Tailwind preset adds the `4/3`, `3/4` and `2/1` aspect ratios.
