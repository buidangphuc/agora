`NativeSelect` renders a real `<select>` with the platform label (optionally screen-reader only), required mark, help and error text and the 44px touch height, so forms submit natively and tests can use `select_option`. The Radix `Select` is unchanged. Tokens add `select.native` and `select.icon`.
